PRZYKŁAD 00 // ZNACZNIK W KODZIE

Metoda przeznaczona do uruchomienia

CleanupJob.java
class CleanupJob {
    @Scheduled(delaySeconds = 30)
    public void removeExpiredFiles() {
        // kod zadania
    }
}
PYTANIE

Co daje zapis @Scheduled?

Metoda otrzymuje metadane. Inny fragment programu może je odnaleźć, odczytać parametr i zdecydować, kiedy wywołać metodę.

01 // MODEL

Adnotacja opisuje element programu

@Override

Informacja dla kompilatora

Kompilator sprawdza, czy metoda rzeczywiście nadpisuje inną metodę.

@Deprecated

Informacja dla narzędzi

IDE i dokumentacja ostrzegają przed użyciem starego API.

@Entity

Informacja dla frameworka

Biblioteka wykrywa klasę i nadaje jej określone znaczenie.

Adnotacja nie wykonuje kodu: znaczenie nadaje jej kompilator, narzędzie albo kod, który ją przetwarza.
02 // STANDARD LIBRARY

Adnotacje obecne w codziennym kodzie

@Override
public String toString() { ... }

@Deprecated(since = "2.0", forRemoval = true)
public void oldApi() { ... }

@SuppressWarnings("unchecked")
void convert() { ... }
ODBIORCA METADANYCH
  1. @Override wspiera kontrolę kompilacji.
  2. @Deprecated opisuje cykl życia API.
  3. @SuppressWarnings steruje wybranymi ostrzeżeniami.
03 // @INTERFACE

Własną adnotację deklaruje @interface

Scheduled.java
public @interface Scheduled {
    long delaySeconds();
    String name() default "job";
    boolean enabled() default true;
}

Element adnotacji przypomina metodę bez parametrów. Jego typ określa rodzaj wartości, którą można zapisać przy użyciu adnotacji.

Terminologia: specyfikacja mówi o elementach adnotacji. W praktyce często nazywa się je parametrami.
04 // UŻYCIE

Wartość wymagana i wartość domyślna

@Scheduled(
    delaySeconds = 30,
    name = "cleanup"
)
void clean() { }

// enabled przyjmie true
REGUŁA

Brak default oznacza wartość obowiązkową

delaySeconds trzeba podać. Pozostałe elementy można pominąć, ponieważ deklaracja określa ich wartości domyślne.

05 // DOZWOLONE TYPY

Elementy adnotacji mają ograniczony zestaw typów

01 typy prymitywne02 String03 Class04 typy wyliczeniowe05 inne adnotacje06 jednowymiarowe tablice tych typów
Niedozwolone: dowolny obiekt, null, typ parametryzowany jako wartość i wielowymiarowa tablica.
06 // SKRÓCONA SKŁADNIA

Element value ma specjalny skrót

public @interface Role {
    String value();
}

@Role("ADMIN")
class AdminPanel { }

// równoważne: @Role(value = "ADMIN")
WARUNEK

Nazwę można pominąć, gdy przypisujemy pojedynczą wartość do elementu o nazwie value. Przy kilku elementach stosujemy zwykły zapis nazwa = wartość.

07 // ADNOTACJE ADNOTACJI

Metaadnotacje definiują kontrakt

@Target

Miejsce użycia

Określa, które elementy programu można oznaczyć.

@Retention

Czas przechowywania

Decyduje, czy informacja trafi do pliku klasy i runtime.

@Documented

Dokumentacja

Powoduje uwzględnienie adnotacji w wygenerowanym Javadoc.

08 // ELEMENTTYPE

Cel użycia ogranicza @Target

@Target({
    ElementType.TYPE,
    ElementType.METHOD
})
public @interface Audited { }
WYBRANE CELE
  1. TYPE dla klasy, interfejsu, enum i rekordu.
  2. FIELD dla pola.
  3. METHOD dla metody.
  4. PARAMETER dla parametru.
  5. ANNOTATION_TYPE dla innej adnotacji.
  6. TYPE_USE dla użycia typu.
09 // CYKL ŻYCIA

Retencja decyduje, kto zobaczy adnotację

SOURCEkod źródłowy
›
CLASSplik .class
›
RUNTIMErefleksja

SOURCE

Znika po kompilacji. Dobre dla kontroli kompilatora i procesorów źródła.

CLASS

Trafia do pliku klasy, ale refleksja nie udostępnia jej w runtime.

RUNTIME

Pozostaje dostępna dla kodu działającego na JVM.

10 // PEŁNA DEFINICJA

Adnotacja przeznaczona dla refleksji

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@Documented
public @interface Scheduled {
    long delaySeconds();
    String name() default "job";
}
KONTRAKT

Refleksja ma odczytać adnotację, więc potrzebujemy RUNTIME. Framework ma szukać jej na metodach, więc wybieramy METHOD.

12 // ANNOTATED ELEMENT

Sprawdzenie adnotacji na klasie

Class<?> type = AdminPanel.class;

if (type.isAnnotationPresent(Role.class)) {
    Role role = type.getAnnotation(Role.class);
    System.out.println(role.value());
}
API

AnnotatedElement

Class, Method, Field i inne elementy refleksji udostępniają wspólny zestaw metod do badania adnotacji.

13 // SKANOWANIE

Wyszukiwanie oznaczonych metod

for (Method method : type.getDeclaredMethods()) {
    Scheduled config = method.getAnnotation(Scheduled.class);

    if (config != null) {
        System.out.printf("%s: %d s%n",
            config.name(), config.delaySeconds());
    }
}
WYNIK

getAnnotation zwraca obiekt implementujący typ adnotacji albo null. Elementy odczytujemy jak metody: config.name().

14 // MINI FRAMEWORK

Uruchomienie metody zgodnie z metadanymi

static void runJobs(Object target) throws Exception {
    for (Method method : target.getClass().getDeclaredMethods()) {
        Scheduled job = method.getAnnotation(Scheduled.class);
        if (job != null && job.enabled()) {
            method.invoke(target);
        }
    }
}
ZAŁOŻENIA
  1. Oznaczone metody nie przyjmują argumentów.
  2. Instancja jest już utworzona.
  3. Błędy wywołania wymagają świadomej obsługi.
15 // KONTRAKT FRAMEWORKA

Refleksja wymaga walidacji założeń

  • sprawdź liczbę i typy parametrów metody,
  • sprawdź modyfikatory oraz typ zwracany,
  • zgłoś czytelny błąd z nazwą klasy i metody,
  • waliduj konfigurację przed właściwym użyciem.
if (method.getParameterCount() != 0) {
    throw new IllegalStateException(
        "@Scheduled wymaga metody bez parametrów: "
        + method);
}
16 // @REPEATABLE

Jedną adnotację można zastosować wiele razy

@Repeatable(Roles.class)
@Retention(RetentionPolicy.RUNTIME)
public @interface Role { String value(); }

@Retention(RetentionPolicy.RUNTIME)
public @interface Roles { Role[] value(); }

@Role("USER") @Role("AUDITOR")
class Report { }
ODCZYT

getAnnotationsByType(Role.class) zwraca wszystkie wystąpienia, niezależnie od reprezentacji kontenera.

17 // @INHERITED

Dziedziczenie adnotacji ma wąski zakres

@Inherited wpływa na wyszukiwanie adnotacji na klasach. Podklasa może wtedy otrzymać adnotację nadklasy przez getAnnotation.

Nie dotyczy: metod, pól, konstruktorów, parametrów ani implementowania interfejsu.
@Inherited
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
public @interface Secured { }

@Secured class BaseService { }
class UserService extends BaseService { }
