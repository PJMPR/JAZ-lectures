# Lambda examples — Java 21

Projekt towarzyszący wykładowi o klasach anonimowych, interfejsach funkcyjnych i lambdach.

```shell
mvn compile
java -cp target/classes pl.pjatk.jaz.lambdas.App
```

`NotificationPipeline.java` zawiera zadanie live coding, a `NotificationPipelineSolution.java` rozwiązanie.
