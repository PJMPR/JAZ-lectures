# Refleksja — przykłady

Projekt demonstracyjny do wykładu `lectures/reflection/index.html`.

Przykład pokazuje uzyskiwanie obiektu `Class`, badanie rodzaju i hierarchii typu, przeglądanie pól, konstruktorów i metod, odczyt podpisów generycznych oraz kontrolowane tworzenie obiektu i wywołanie metody.

Uruchom klasę `pl.pjatk.jaz.reflection.App` w IDE lub wykonaj:

```shell
mvn compile exec:java -Dexec.mainClass=pl.pjatk.jaz.reflection.App
```
