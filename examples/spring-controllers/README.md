# Spring Controllers

Przykład do wykładu 09: kontroler REST, mapowanie URL, parametry ścieżki i query, rekordy DTO, walidacja oraz obsługa błędów.

Uruchomienie: `mvn spring-boot:run`. Aplikacja nasłuchuje pod adresem `http://localhost:8088/jaz`.

Endpointy: `GET /api/books`, `GET /api/books/{id}`, `POST /api/books`, `PUT /api/books/{id}`, `DELETE /api/books/{id}`.
